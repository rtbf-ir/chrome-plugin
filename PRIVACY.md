# Privacy policy

The Right to be Forgotten extension only reads the address of the active tab **after the user opens the extension**. It compares that hostname with the public directory at `rtbf.ir` to show the account-deletion difficulty and, when available, a deletion link.

The extension does not collect browsing history, account credentials, form contents, cookies, personal identifiers, or analytics. It does not transmit the active URL to RTBF or any other third party.

To keep the directory available offline briefly, the extension stores a cached copy of the public directory and its refresh time locally in the browser for up to 24 hours. Users can remove this data by uninstalling the extension or clearing the extension's local storage.

The only network request made by the extension is a request for the public directory at `https://rtbf.ir/data/data.json`.
